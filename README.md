# Reduce Memory 4.0

Portable memory-reclaim application for Windows and Linux.

## Downloads

- Windows: open `windows/ReduceMemory.exe` or `windows/ReduceMemory_x64.exe`.
- Linux desktop: run `linux/desktop/Install_Desktop.sh`.
- Linux server: run `linux/server/Install_Server.sh`.
- Linux manual launcher: `linux/ReduceMemory_Linux.sh`.

The matching frontend and worker binaries are already included in the
`windows` directory. Keep the files in that directory together.

The full development source, tests, engineering documents, and CI workflow
remain preserved on branch `codex/phase2-luna-20260913`. This `main` branch is
the clean application distribution branch.

See `SHA256SUMS.txt` and the GitHub Release `v4.0` for package checksums and
release provenance.
